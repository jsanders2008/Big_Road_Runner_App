# Big Road Runner App

A dedicated mobile companion app designed for commercial truck drivers and owner-operators to manage professional driver credentials, log trips and fuel expenses, monitor safety alerts, and fetch real-time route weather conditions.

## Key Features
- **Driver Profile & Credential Manager**: CDL license, medical card expiration alerts, truck specifications, and USDOT numbers.
- **Trip Log & Mileage Tracker**: Record completed/active hauls, odometer readings, fuel gallons, fuel costs, and average fleet MPG.
- **Live Route Weather REST API**: Real-time city weather forecasts, wind speeds, humidity, and road safety advisories powered by Open-Meteo REST API.
- **Interactive Dual Light Sweep Intro**: High-contrast dark mode splash screen with custom metallic gold logo animations.
